# Reproduction status

The source scripts retain the analysis settings and random seeds used for the reported calculations. The frozen summaries were copied from completed analyses and are supplied for numerical comparison. They are not regenerated by the smoke check.

The required release verification runs syntax checks, installed-dependency checks, deterministic core-function checks, and count consistency against frozen national results. Explicit optional switches additionally import all analysis modules or fit a small synthetic LightGBM model. A synthetic model fit is recorded only when the smoke report contains a non-null synthetic_validation_r2. This is not a rerun of the complete soil analysis. Full model benchmarks, the 30-repetition reference-contamination experiments, and external-source harmonisation require the public inputs and appreciably more computing time.

The completed regression benchmark covers Pb, As, Cu and Zn. A larger attempted benchmark was incomplete because of memory exhaustion; the release instructions use only the four completed targets. Cross-conformal national calibration is approximate, and data-adaptive trimming changes the calibration distribution. Simulation error rates apply to their specified perturbations and do not establish an unconditional finite-sample error guarantee for the national map.

Source-proximity matches are a spatial rule, not measured contamination labels. Their natural-reference match prevalence is capped at 5%; this does not identify a 5% false-label probability. The table column expected_rule_matches is 50 times the marginal rule-match share. The corresponding original calculation is numerically unchanged.

Derived apparent penetration depths summarise horizon composites under a uniform mixing model. Land-use contrasts are adjusted observational comparisons whose causal interpretation needs additional assumptions.
